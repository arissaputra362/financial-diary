# Financial Planner UI/UX Design System & Specification

Welcome to the UI/UX design specifications for the Financial Planner MVP. This is a mobile-first **family budgeting app**. Beranda follows the confirmed R-9 ordering: **expense hero first (span-12 on desktop), two separate wallet totals, wallets, recent activity, budget, chart, goals**. **Finny is not on Beranda**; the advisor panel + drawer live on `/budget` only (exact `/home` behavior). Bento containers group these tasks, while the compact app header and bottom navigation keep the product feeling like a real finance app.

> **OCR retry UX amendment (PM-approved UX for T-012, 2026-10-22, revised 2026-10-23):** doc 03 §3.5 records the PM-approved failure/retry design. `Pindai ulang` opens the native file picker so the user can pick the same photo or a different photo. Different bytes follow the normal upload path and create a new receipt. Identical bytes are recognized by dedup and re-run OCR for the latest uploader-owned `FAILED` job on the server's privately stored image, as a new `OcrJob` attempt with the old attempt retained and no duplicate receipt. If the identical file is chosen while the stored image is missing or unreadable, the card shows the honest unavailable state with `Pilih foto struk` (opens the picker for a different photo), `Isi manual`, and `Batal`; the old job is not retried automatically. There is no availability preflight and `Pindai ulang` is hidden in that state. Close/reset of `?add=1` returns focus and lets the Add action reopen immediately; final labels: `Pindai ulang`, `Isi manual`, `Pilih foto struk`, `Batal`, with `Memindai ulang` as the retry loading label. ## 🎨 Key Visual Aesthetics (canonical summary, links to tokens)

- **Palette (blue-white-green, doc 01 §2):** canvas `#F1F5FA`, cards `#FFFFFF`, structure/nav/Finny/dompet Bersama surface `#14273F` (navy), uang biru (expense bars, selected states, scan/AI accent, dompet Pribadi surface) `#1D4F87`, blue tints `#DCEBFA` / `#EFF4FA`, action green `#166534` (CTA, FAB, income `+`, target bars, ATM chip); text tokens measured `#17304F`/`#46597A`/`#5C7191`/`#5C6C86` (doc 01 §2.2).
- **Amber and red are status colors only** (pending, approaching limit, errors, destructive confirmations), never brand or decoration, and **never for ordinary uang-keluar amounts** (those are neutral ink + `-`; the money-out identity is blue, doc 01 §2.3). Always icon + label + color (doc 01 §2.3). Purple/violet/fuchsia are retired.
- **Shapes:** super-rounded corners (`rounded-3xl` for bento cards, sheets, modals; `rounded-full` for all buttons, tabs, and tags; `rounded-2xl` inputs).
- **Icons/navigation:** every nav item is a meaningful inline SVG line icon + text label; circular icon badges; category badges keep the functional `CATEGORY_TONES` coding (doc 01 §5.5).
- **Typography (doc 01 §3, updated 2026-10-20):** single family, Plus Jakarta Sans (display, body, and money figures; money uses `tabular-nums` for alignment); titles normal-case and quieter than money figures; uppercase reserved for micro-labels.
- **Wallet cards (doc 06 §4, tokens doc 01 §5.6):** solid navy (Bersama) or blue (Pribadi) landscape card with abstract green chip and contactless glyph; balance is the focal point; no card number, expiry, CVV, holder name, bank logo, network mark, or security claim.

## 🧭 Designed for first-time users

The design uses outcome-first language so people can use it without a guide:

- **Beranda (R-9 order)** opens with `Uang keluar bulan ini`, then the two separate money totals (`Uang tersedia bersama`, `Dompet pribadiku`, never summed), wallets, and recent activity.
- **Tambah transaksi** offers `Isi manual` or `Scan struk`; technical terms such as OCR and the model name stay in implementation notes.
- **Pagination is cursor-based:** `Muat lebih banyak` appends the next batch; no page numbers (matches the actual `TransactionList.tsx` contract).
- Buttons describe what will happen: `Simpan transaksi`, `Izinkan bergabung`, `Periksa lagi`, `Pindahkan ke Trash`.
- **Keluarga** replaces admin language, and the waiting room replaces the cold 403 screen.
- **Buat dompet** may name a bank via `07-bank-institutions.md`, or proceed as `Dompet manual / bank lain`.
- Each section has one clear primary action, while unfamiliar actions include short helper text.

The detailed rules live in [01-design-system-tokens.md](01-design-system-tokens.md) under **Plain-language interaction contract**.
