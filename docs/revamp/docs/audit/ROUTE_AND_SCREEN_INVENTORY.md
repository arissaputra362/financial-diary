## Findings and limits

- Route inventory is cross-checked against filesystem routes, the actual navigation components, docs/current-state.md, and embedded component entry points.
- docs/current-state.md lists / as session-sensitive; current app/page.tsx itself redirects to /home, while the request proxy/auth flow controls access. Keep this wording precise in later documentation.
- The October 5 sibling journey map marks wallets and later features “not started”; those statuses are outdated against current wallet components/API and later T-009/T-011 QA evidence.
- Route files establish responsive breakpoints and theme wiring, but a fresh visual review at the specified mobile/tablet/desktop matrix remains a later verification task.
- API endpoints are catalogued in DATA_AND_INTEGRATION_MAP.md; they are not duplicated as user-facing screens here.
